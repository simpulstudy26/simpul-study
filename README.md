# 심풀스터디 3.0 (2학기 기말고사용)

**시험 버전 3가지**를 홈·과목 화면 위쪽에서 고를 수 있습니다: 1학기 기말(1.0 자료 그대로) · 2학기 중간(2.0 자료) · 2학기 기말(기본값, 지금 시험).
- 2학기 중간 자료 17개는 USB의 `simpul-study-2.0/materials/inbox/<과목>/html/`에서 가져와 `site/materials/s2-mid/`에 두었습니다. 2.0의 수학은 강의 녹취 원문뿐이라 넣지 않았습니다.
- 고른 버전은 기기에 저장되고, 주소 끝에 `?v=s1-final` / `?v=s2-mid` / `?v=s2-final`을 붙여 바로 열 수도 있습니다.
- 예전 1.0 주소(예: `/korean_phonology.html`)로 들어오면 1학기 기말 버전으로 그 자료가 열립니다.
- 범위 개념·AI 문제 만들기·맥북 자동 출제는 지금 시험(`catalog.js`의 `DEFAULT_VERSION`) 기준입니다. 다음 시험으로 넘어갈 때 이 값을 바꾸세요.

고1 과목별 내신 대비 자료 사이트입니다. 1.0의 학습 자료를 그대로 살리고, 홈·과목·자료 보기 화면을 새로 만들었습니다.

## 폴더 구조

- `site/` — 실제로 배포하는 사이트 전체 (Cloudflare Pages에 이 폴더를 올립니다)
  - `index.html` 홈 (과목 고르기, 이어서 보기, 자료 찾기)
  - `subject.html?s=korean` 과목별 자료 목록
  - `view.html?id=…` 자료 보기 (1.0 자료를 그대로 보여 주고 이전·다음 자료로 이동)
  - `cloud.html` 무한 문제 · `make.html` 내 문제 만들기 · `admin.html` 관리자
  - `teacher.html`·`automation.html` 관리자 맥북 전용 도구 (로컬 서버에서만 작동)
  - `materials/<과목>/` 학습 자료 HTML (지금은 1.0에서 남긴 정보·일본어만)
  - `scripts/catalog.js` **자료 목록(버전별). 자료를 추가·수정할 때는 해당 버전·과목의 items만 고치면 됩니다.**
  - `_redirects` 1.0 주소(예: `/korean_phonology.html`)로 들어온 학생을 새 주소로 보냄
- `server.py` — 맥북에서 사이트와 출제실 API를 함께 여는 로컬 서버
- `SIMPUL 실행.command` — 더블클릭하면 로컬 서버가 켜지고 브라우저가 열립니다

이전 테스트 버전 파일(`index.html`, `portal.html`, `scripts/`, `styles/`, `assets/`)은 폴더 바로 아래에 남아 있지만 더 이상 쓰지 않습니다. 확인 후 지워도 됩니다.

## 시험범위 (+ 듀오링고 학습 경로)

범위 자료는 **`scripts/ranges.js`의 `RANGES` 한 곳**에만 있습니다. 시험범위 페이지와 듀오링고 학습 경로가 둘 다 여기서 읽습니다.
- `exams.html` — 상단 메뉴 ‘시험범위’. 과목별 범위·단위 수, 범위마다 체크, 과목 탭·검색.
- 듀오링고 학습 경로(홈) — 시험범위를 **12쪽 안팎 단계**로 나눈 길. 단계를 눌러 그 쪽을 공부하고 ‘공부했어요’를 누르면 완료, 끝까지 가면 범위를 한 번 다 본 것. 과목 탭에 `완료/전체` 표시.
- 두 화면의 체크는 같은 기록(`simpul.range.v1`, 이 기기에만)이라 한쪽에서 체크하면 다른 쪽에도 반영됩니다. 페이지 범위는 단계 일부만 하면 시험범위 페이지에 `n/m단계`로 보입니다.
- **자동 업데이트**: 경로는 열 때마다 문제 은행(`cloud/<과목>.json`)·문제 생성기·내가 만든 문제의 단원과 `catalog.js` 2학기 기말 자료를 다시 모읍니다.
  - 단원 이름이 범위의 `units`에 있거나 `match` 낱말을 포함하면 그 범위 구간에 **? 문제 레슨**으로 붙습니다(예: 수학 ‘명제’·‘함수’, 일본어 ‘일본어’).
  - catalog 자료에 `range: '범위 id'`(예: `range: 'in-3'`)를 적으면 그 구간에 **≡ 자료**로 붙습니다.
  - 어디에도 안 맞는 단원·자료는 그 과목 경로 끝 **‘추가된 문제·자료’**에 나옵니다. 그래서 새 자료나 문제가 생기면 고치지 않아도 경로에 나타나고, 원하면 `units`/`match`/`range`로 제자리에 옮기면 됩니다.
- 범위가 바뀌면 `RANGES`의 해당 줄만 고치세요. 줄의 `id`(예: `en-5`)는 공부 기록 키라 바꾸지 말고, 새 범위는 새 id로 추가합니다. 다음 시험으로 넘어갈 때는 `ranges.js`의 저장 키 `KEY`도 바꾸세요.
- 파일: `exams.html`, `scripts/ranges.js`, `scripts/exams.js`, `styles/exams.css`, 경로는 `scripts/duo-home.js`·`styles/duo.css`

## 공부 타이머 (열품타 참고)

`timer.html` — 상단 메뉴 ‘공부 타이머’. 디자인과 흐름은 열품타 앱을 따름(공개 앱 화면 이미지에서 색 추출: 주황 헤더 #EF6C00, 과목 버튼 색 등). 과목의 색 동그라미 재생 버튼을 누르면 어두운 ‘공부 중’ 화면(그 과목 시간 · 오늘 · 현재 집중)이 열리고, 일시정지하면 기록 후 목록으로. 탭: 타이머 / To-do / 통계. 오늘 순공 시간, 하루 목표, D-day, 오늘 할 일, 과목별 기록(오늘·최근 7일), 최근 7일 막대그래프, 집중 화면(전체 화면 큰 시계), 딴짓 방지(다른 탭·앱으로 가면 멈춤).
- 시작 시각만 저장하고 계산하므로 탭을 닫거나 화면이 꺼져도 정확합니다. 자정을 넘기면 날짜별로 나눠 기록하고, 켜 둔 채 잊은 경우 12시간까지만 기록합니다.
- 홈 위쪽 줄에 오늘 공부 시간과 지금 공부 중인 과목이 실시간으로 보입니다.
- 타이머를 켠 채 심풀스터디의 다른 기능을 쓸 수 있습니다. 공부 중 화면의 ‘공부하러 가기’(과목 자료·무한 문제·문제 만들기)나 ‘접기’를 누르면 타이머는 계속 돌고, 학생용 페이지 오른쪽 위에 작은 타이머(과목·시간·일시정지)가 보입니다(`scripts/timerbar.js`, 레슨 전체 화면에서는 숨김).
- 딴짓 방지는 사이트 안 이동은 허용하고 사이트 밖(다른 탭·앱)만 멈춥니다. 페이지를 떠난 시각을 적어 두고, 5초 안에 심풀스터디 페이지가 열리면 계속, 같은 페이지로 돌아오거나 늦게 열리면 떠난 시각까지만 기록하고 멈춥니다(`studytime.js`).
- 기록은 이 기기에만 저장됩니다(`simpul.timer.v1`).
- **랭킹 탭 (반 그룹)**: 그룹을 만들면 6글자 초대 코드가 생기고, 친구는 코드와 닉네임으로 참여합니다. 그룹 안 순위(오늘·최근 7일)와 **반 랭킹**(2명 이상 그룹끼리 1인 평균 공부 시간, 30위까지)을 보여 줍니다.
  - 그룹은 한 기기당 5개까지 참여, 3개까지 만들기, 그룹당 60명. 같은 그룹 안 닉네임은 겹칠 수 없습니다. 만든 사람은 멤버를 내보낼 수 있고, 만든 사람이 나가면 가장 먼저 들어온 사람이 이어받습니다. 아무도 없으면 그룹이 지워집니다.
  - 서버로 가는 것: 그룹에 들어간 기기만, 최근 8일 **날짜별 공부 시간 합계(초)**와 닉네임. 과목·할 일·D-day는 보내지 않습니다. 하루 24시간이 넘는 값은 잘라 냅니다. 어느 그룹에도 없게 되면 그 기기의 공부 시간 기록은 서버에서 지웁니다.
  - 학생 구분은 기기 익명 번호뿐이라, 마음먹고 값을 조작하는 것까지 막지는 못합니다(친구끼리 동기 부여용).
  - 관리자 페이지 ‘공부 타이머 랭킹 그룹’에서 그룹 목록을 보고 부적절한 이름의 그룹을 지울 수 있습니다.
  - API: `cloudflare/api.js`의 `study/sync`, `groups/*` (D1 표 `study`, `study_groups`, `members`는 처음 요청 때 자동으로 만들어짐). 맥북 로컬 서버(`server.py`)에는 랭킹 API가 없어 안내 문구만 보입니다. 로컬에서 시험하려면 `npx wrangler pages dev`.
  - 파일: `scripts/timer-rank.js`, `styles/timer.css`(랭킹 부분), 동기화는 `scripts/studytime.js`의 `syncRank`
- 파일: `scripts/studytime.js`(기록 계산), `scripts/timer.js`, `styles/timer.css`

## 듀오링고 모드 (2학기 기말 버전 전용)

홈·무한 문제 화면 위쪽의 **듀오링고 모드** 스위치로 켜고 끕니다. 기본은 꺼짐이고, 다른 시험 버전에서는 스위치가 숨고 저장된 설정과 관계없이 꺼집니다(`scripts/duo.js`의 `ONLY_VERSION`).
- 홈: 연속 학습일(7일마다 방패 1개, 하루 빠져도 지켜 줌), 하루 목표 XP, 일일 퀘스트 3개, 틀린 문제 복습, 시험범위 학습 경로(범위를 12쪽 안팎 단계로 나눔, 문제 단원은 10문제 정답이면 완료 · 위 ‘시험범위’ 참고)
- 무한 문제: 5문제 레슨, 진행 막대·연속 정답, 채점 결과 카드, 틀린 문제는 레슨 끝에 한 번 더, 결과 화면(정답 10 XP + 완료 5 + 완벽 5)
- 레슨 화면 `lesson.html?s=과목&u=단원` (복습은 `&mode=review`): 학습 경로·복습 버튼에서 열리는 전체 화면 레슨. 보기 고르기 → 확인 → 아래 결과 패널 → 계속, 틀린 문제는 끝에 다시(최대 2번), 레슨 완료·연속 학습 화면. 듀오링고 모드가 꺼져 있으면 무한 문제로 이동
- 틀린 문제는 28일 동안 보관하고 맞히면 빠집니다. 키보드: 숫자 1~5로 보기 고르기, Enter로 계속
- 기록은 이 기기에만 저장됩니다(`simpul.duo.v1`). 파일: `scripts/duo.js`, `scripts/duo-home.js`, `styles/duo.css`

## 사전 (영어·국어·일본어)

과목과 따로, 메뉴의 **사전**(`dict.html`, `dict.html?d=ko&q=단어`로 바로 열기)에서 위쪽 탭으로 **영어사전·국어사전·일본어사전**을 골라 뜻·발음(▶ 재생)·예문을 찾습니다. 고른 사전은 기기에 저장됩니다(`simpul.dict.mode`).
- 일본어사전(`d=ja`)은 한자 표기와 가나 읽기(学校 がっこう), 예문·뜻의 후리가나, 한자 한 글자의 음독·훈독과 음훈(食: しょく·じき · 밥 식)을 보여 줍니다. 한국어로 찾으면 한일사전 결과가 나옵니다. 네이버 주소: `https://ja.dict.naver.com/api3/jako/search?…`(Referer `https://ja.dict.naver.com/` 필요), 자동완성 `ac-dict.naver.com/jako/ac`.
  - 후리가나는 서버가 `{学校|がっこう}`로 바꿔 보내고 화면이 `<ruby>`로 다시 그립니다(네이버 HTML을 그대로 넣지 않음).
- 국어사전은 표준국어대사전·고려대 한국어대사전 결과로, 동형어 번호(사과⁵), 한자(沙果), 표준 발음, 비슷한말·반대말(눌러서 바로 찾기)도 보여 줍니다. 네이버 주소: `https://ko.dict.naver.com/api3/koko/search?…`(Referer `https://ko.dict.naver.com/` 필요), 자동완성 `ac-dict.naver.com/koko/ac`.
- 자료 보기에서 단어를 두 번 누르면 영어 단어는 영어사전, 한글은 국어사전, 가나·한자는 일본어사전에서 찾습니다(조사가 붙은 ‘음운은’도 ‘음운’으로 나옴).
- 입력하면 추천 단어가 뜨고(↑↓·Enter), 최근 찾은 단어가 칩으로 남습니다.
- ☆ 단어장으로 모은 단어는 오른쪽 **내 단어장**에 쌓이고, ‘뜻 가리기’로 외우기 연습을 합니다. 단어장·최근 검색은 이 기기 브라우저에만 저장됩니다(`simpul.wordbook.v1`, `simpul.dict.recent.v1`).
- 자료 보기(`view.html`)에서는 위쪽 **사전** 버튼으로 작은 사전 창을 열거나, 자료 안의 영어 단어를 두 번 누르면 바로 뜻이 뜹니다.
- 내용은 네이버 영어사전 웹이 내부에서 쓰는 API를 서버가 대신 불러 정리한 것입니다(브라우저에서 직접 부르면 막힘).
  - 검색 `https://en.dict.naver.com/api3/enko/search?query=…&m=pc&range=all&lang=ko` — `Referer: https://en.dict.naver.com/` 헤더가 없으면 빈 응답
  - 자동완성 `https://ac-dict.naver.com/enko/ac?st=11&r_lt=11&q=…`
  - 발음 mp3는 서명된 주소라 그대로 재생됩니다.
- 사이트 쪽 주소: `GET /api/dict?d=en|ko|ja&q=`, `GET /api/dict/ac?d=en|ko|ja&q=` (d가 없으면 영어) — 배포 사이트는 `cloudflare/api.js`(하루 캐시, D1 안 씀), 맥북은 `server.py`(서버가 켜져 있는 동안 메모리 캐시). 정리 규칙은 두 파일이 같습니다.
- **공식 API가 아닙니다.** 네이버가 형식을 바꾸거나 Cloudflare 서버 주소를 막으면 사전이 “사전 서버에 연결하지 못했어요”로 멈출 수 있습니다. 결과 화면에 출처(네이버 영어사전·원 사전명)와 원문 링크를 함께 보여 줍니다.
- 파일: `site/dict.html`, `site/scripts/dict.js`, `site/styles/site.css`의 ‘영어사전’ 부분

윈도우처럼 Python이 없는 PC에서는 `node cloudflare/dev-server.mjs 8012`로 미리보기를 열 수 있습니다(사전·자료 보기·무한 문제는 작동, D1이 필요한 API는 503). 미리보기 설정 이름: `simpul-windows`.

## 자동 출제 + 무한 문제 클라우드 (3.1)

`SIMPUL 실행`으로 서버를 켜면 자동화 엔진이 함께 켜집니다.

- **자동화 센터** http://127.0.0.1:8001/automation.html — 자료를 끌어다 놓으면 끝
- **무한 문제 클라우드** http://127.0.0.1:8001/cloud.html — 학생용, 배포 사이트에서도 작동
- **자료 폴더** `inbox/<과목>/` (예: `inbox/수학/이차방정식/파일.pdf`) — 넣으면 5초 안에 자동 처리, 처리한 원본은 `data/inbox-done/`으로 이동

자동 처리 순서: 저장·중복 확인 → 글자 추출(PDF는 macOS PDFKit, DOCX/RTF는 textutil, 스캔본·사진은 원본을 AI에 전달)
→ 과목 미지정 시 AI가 과목·단원 판별 → 5문항씩 생성(5지선다·단답형) → 형식 검사·중복 제거 → AI 정답 재검증
→ 통과한 문제는 `site/cloud/<과목>.json`에 공개, 검증 실패는 자동화 센터 ‘검토 대기’로.

무한 보충: 서버가 켜져 있는 동안 단원별 공개 문항 수가 목표(기본 40)보다 적으면 1분마다 10문항씩 보충합니다.
학생이 클라우드에서 새 문제를 거의 다 풀면(로컬 서버에서 연 경우) 그 단원 보충을 자동으로 요청합니다.
정보·일본어는 브라우저 문제 생성기(`scripts/generators.js`)가 서버 없이 끝없이 새 문제를 만듭니다. 수학(2학기 기말 범위: 명제, 함수)은 아직 문제가 없습니다.

AI 공급자 (`simpul_auto/providers.py`)
- API: Google Gemini (`GEMINI_API_KEY`, 기본 모델 `gemini-3.5-flash`, 과부하 시 `gemini-flash-lite-latest`로 전환. `GEMINI_MODEL`로 변경)
- 로컬: Ollama (`OLLAMA_HOST`, 모델은 자동화 센터에서 선택). 2019 Intel MacBook에서 7B 모델은 5문항에 20분 이상 걸려 실사용이 어렵습니다.
- ‘자동’은 API를 먼저 쓰고 실패·한도 초과 시 로컬로 넘어갑니다. 무한 보충은 설정에서 ‘로컬 AI만’으로 바꾸면 API를 쓰지 않습니다.

저장 위치: `data/simpul.db`(자료·작업·문제, 배포 안 됨), `data/uploads/`(올린 원본), `site/cloud/`(공개 문제, 배포됨).
배포 사이트에 새 문제를 반영하려면 `site` 폴더를 다시 배포하세요. `SIMPUL_DEPLOY_CMD` 환경변수에 배포 명령을 넣으면 공개 후 10분에 한 번씩 자동 배포합니다.
예: `export SIMPUL_DEPLOY_CMD="npx wrangler pages deploy site --project-name simpul-study"`

## 자료 추가하기

1. HTML 파일을 `site/materials/<과목>/`에 넣습니다.
2. `site/scripts/catalog.js`의 해당 과목 `items`에 한 줄을 추가합니다.
   `{ id: '고유-이름', kind: 'note', title: '자료 제목', course: '단원', file: '<과목>/파일.html' }`
   kind는 note(개념 정리), exam(문제·모의고사), quiz(퀴즈), practice(바로 풀기), link(외부 자료) 중 하나입니다.
3. (선택) 사이트 디자인에 맞추기: `python3 tools/restyle_material.py <원본.html> site/materials/<…>/<파일.html>`
   자료의 색을 shadcn/ui zinc 토큰으로 바꿔 사이트와 같은 다크·라이트 모드를 따르게 하고, `site/materials/_theme/`의 React Bits 움직임(BlurText·SpotlightCard·AnimatedContent·ClickSpark)을 붙입니다.
   2학기 기말 영어·통합사회 자료(`site/materials/s2-final/`)는 Google Drive ‘심풀스터디 2학기 기말’ 폴더 원본을 이렇게 바꾼 것입니다.
4. 자료 안의 문제를 무한 문제로 옮기기 (문제는 과목 자료에서 빼고 무한 문제에서만 풀어요)
   1) 문제가 들어 있는 원본을 `tools/material-src/<과목>/`에 둡니다(restyle을 거친 파일).
   2) `node tools/build_material_bank.mjs` → `site/banks/<과목>.json`, `site/banks/index.json`
   3) `python3 tools/strip_material_quiz.py` → `site/materials/s2-final/`의 자료에서 문제를 빼고, 그 자리에 무한 문제 단원 카드를 넣습니다.
   - 지금은 영어(교과서 어휘, 부교재 어법·낱말·어휘 O/X·제목·글의 순서·요약문 빈칸·문장 배열)와 통합사회(OX·객관식·고난도)를 옮깁니다.
   - `cloud/*.json`은 자동화 엔진이 DB에서 다시 쓰기 때문에 자료 문제는 `banks/`에 따로 둡니다. `scripts/bank.js`가 둘을 합쳐 무한 문제·듀오링고 레슨·학습 경로에 보여 줍니다.
   - O/X 문제 형식: `{ t: 'ox', q, c: ['O','X'], a: 'O' 또는 'X', e }`. 무한 문제·레슨에서 큰 O/X 버튼으로 나오고 키보드 O·X로도 답합니다.
   - 듀오링고 모드에서 과목 화면에 들어가면, 문제가 있는 과목(지금은 영어·통합사회·정보·일본어)은 맨 위에 ‘문제 레슨’(레슨 시작·단원별 진행)이 나옵니다.

## 로컬에서 열기

`SIMPUL 실행.command`를 더블클릭하거나 터미널에서 `python3 server.py --port 8001 --open`

- 학생용 홈: http://127.0.0.1:8001/index.html
- 출제실: http://127.0.0.1:8001/teacher.html
- 자동화 센터: http://127.0.0.1:8001/automation.html
- 무한 문제 클라우드: http://127.0.0.1:8001/cloud.html

출제실은 `GEMINI_API_KEY` 환경변수를 먼저 쓰고, 없으면 `/private/tmp/simpul-google-api-key` 파일을 읽습니다.
`/private/tmp`는 재부팅하면 지워질 수 있으니 환경변수 사용을 권장합니다. 키를 `site/` 안에 넣지 마세요.

## 사용자와 관리자

| 누구 | 할 수 있는 것 | 페이지 |
|---|---|---|
| 학생(로그인 없음) | 범위 개념 보기, 무한 문제 풀기, AI로 내 문제 만들기 | `index`, `subject`, `cloud`, `make` |
| 관리자(비밀번호) | 범위 개념 업데이트(자료 업로드), 사용자 수, API 키·모델·하루 한도 | `admin.html` |
| 관리자 맥북 | 공용 문제 은행 대량 자동 출제 | `automation.html`, `teacher.html` (로컬 서버에서만, 배포 사이트에서는 관리자 페이지로 이동) |

- 학생이 만든 문제는 **서버에 저장하지 않고 그 학생 브라우저에만 저장**돼서 본인만 볼 수 있습니다.
- 학생은 기기마다 무작위 익명 번호로만 구분합니다(이름·이메일 수집 없음). 현재 사용자 수와 하루 횟수 제한에만 씁니다.
- 관리자 ‘사용자 현황’: 관리자로 로그인한 기기는 모든 숫자에서 빠집니다(‘초기화’로 표시를 지울 수 있음). 오늘 방문 기기를 **처음 온 기기 / 다시 온 기기**로 나누고, **들어온 횟수**(새 탭·새로 연 브라우저마다 1번)를 따로 셉니다.
  한 사람이 여러 기기·시크릿 창으로 들어온 경우를 위해 **같은 인터넷 연결(IP 해시 8글자) + 같은 기기 종류(‘iPhone · Safari’ 등)**를 한 사람으로 보고 ‘오늘 추정 인원’을 계산하고, 같은 연결에서 2대 이상 들어온 묶음을 ‘중복 의심 묶음’으로 보여 줍니다. 학교 와이파이처럼 여럿이 한 연결을 쓰면 같은 기종 친구들이 합쳐질 수 있어 추정치입니다. IP·User-Agent 원문은 저장하지 않습니다.
- 학생 문제는 관리자가 올린 범위 개념 안에서만 만들어지고, 정답 검사를 통과한 문제만 전달됩니다(관리자 페이지에서 끌 수 있음).
- 학생 API·관리자 API 코드: `cloudflare/api.js` (진입점 `functions/api/[[path]].js`), 데이터: Cloudflare D1.

## Cloudflare 배포 (처음 한 번)

학생용 API가 있어서 **대시보드에 폴더를 끌어다 놓는 방식은 안 됩니다**(Functions가 빠짐). 터미널에서 simpul-3.0 폴더 기준으로:

1. 로그인: `npx wrangler login`
2. 데이터베이스 만들기: `npx wrangler d1 create simpul` → 출력된 `database_id`를 `wrangler.toml`에 붙여 넣기
3. 관리자 비밀번호 등록: `npx wrangler pages secret put ADMIN_PASSWORD --project-name simpul-study`
4. (선택) API 키 등록: `npx wrangler pages secret put GEMINI_API_KEY --project-name simpul-study` — 관리자 페이지 ‘API 관리’에서 넣어도 됩니다
5. 배포: `npx wrangler pages deploy`
6. `https://<사이트>/admin.html`에서 로그인 → ‘범위 개념 업데이트’에 2학기 자료 올리기

이후 배포는 5번만 하면 됩니다. 표는 처음 요청 때 자동으로 만들어집니다.

로컬에서 Cloudflare 기능까지 시험하려면 `.dev.vars` 파일에 `ADMIN_PASSWORD=...`와 `GEMINI_API_KEY=...`를 적고 `npx wrangler pages dev`를 실행하세요(`.dev.vars`는 배포되지 않습니다).

### 무료 운영 (비용 0원)

- Cloudflare Pages·Functions·D1과 Gemini API 모두 무료 등급으로 돌아갑니다. 결제 정보를 연결하지 마세요(연결하면 유료 등급으로 바뀝니다).
- Gemini 무료 사용량은 **모델마다 따로**라서, 기본 모델(`gemini-3.5-flash-lite`)이 막히면 `gemini-3.1-flash-lite` → `gemini-3.8-flash` 순서로 넘어갑니다. 관리자 페이지 ‘API 관리’에서 바꿀 수 있습니다. 맥북 쪽은 `GEMINI_MODELS` 환경변수(쉼표로 구분)로 바꿉니다.
- 무료 한도를 학생들이 나눠 쓰므로 기본값은 **학생 1명 하루 5번, 사이트 전체 하루 300번**입니다. 한도가 차면 학생에게 “무한 문제는 계속 풀 수 있어요”라고 안내합니다.
- 정확한 무료 한도는 공개되지 않고 Google AI Studio의 사용량 화면에서만 보입니다. 거기서 확인하고 ‘사이트 전체 하루 최대 횟수’를 맞추세요.
- **무료 등급에 보낸 내용은 Google이 서비스 개선에 쓸 수 있습니다.** 그래서 학생 화면과 관리자 화면에 개인정보를 쓰지 말라는 안내를 넣었습니다.
- AI 없이도 끝없이 나오는 문제(정보·일본어 생성기)와, 맥북에서 미리 만들어 둔 공용 문제 은행은 API를 전혀 쓰지 않습니다.
