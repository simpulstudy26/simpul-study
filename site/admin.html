사용자는 로그인 없이 브라우저마다 익명 번호로 세요. 같은 브라우저로 여러 번 들어오면 기기 1대, ‘들어온 횟수’는 새 탭·새로 연 브라우저마다 1번씩 늘어요. 한 사람이 폰·노트북·시크릿 창으로 들어오면 기기가 여러 대로 잡혀서, 같은 인터넷 연결 + 같은 기기 종류는 한 사람으로 보고 ‘추정 인원’을 계산해요. 학교 와이파이처럼 여럿이 한 연결을 쓰면 같은 기종 친구들이 한 명으로 합쳐질 수 있어 정확하지 않아요. IP 주소 원문과 브라우저 정보 원문은 저장하지 않아요(해시 8글자와 ‘iPhone · Safari’ 같은 이름만). 관리자로 로그인한 기기는 모든 숫자에서 빠져요. ‘지금 접속 중’은 최근 5분 안에 사이트를 보고 있던 기기 수예요.
