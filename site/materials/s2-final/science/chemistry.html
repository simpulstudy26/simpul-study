산과 염기를 구분하는 기준

산은 수용액에서 수소 이온 H⁺를, 염기는 수용액에서 수산화 이온 OH⁻를 내놓는 물질입니다. 산의 공통 성질은 H⁺, 염기의 공통 성질은 OH⁻ 때문에 나타납니다.
비교 기준산성 수용액염기성 수용액
공통 이온H⁺ (수소 이온)OH⁻ (수산화 이온)
예묽은 염산 HCl, 아세트산 CH₃COOH수산화 나트륨 NaOH, 수산화 칼륨 KOH
전기 전도이온이 이동하므로 전류가 흐름이온이 이동하므로 전류가 흐름
탄산 칼슘 CaCO₃반응하여 CO₂ 기체 발생이 실험에서는 뚜렷한 기체 발생 없음
마그네슘 Mg반응하여 H₂ 기체 발생이 실험에서는 뚜렷한 기체 발생 없음
두부의 단백질이 실험의 염기 반응과 구별단백질이 풀어지며 뿌옇게 흐려짐
산과 반응하는 기체를 구별하세요. 탄산 칼슘 → CO₂, 마그네슘 → H₂. 모든 금속이 묽은 산과 반응하여 수소를 만드는 것은 아닙니다.

이온화와 전류의 흐름

물에 녹아 이온이 되면 양이온과 음이온이 각각 전극 쪽으로 이동할 수 있습니다. 같은 산성을 띠어도 음이온은 다를 수 있고, 같은 염기성을 띠어도 양이온은 다를 수 있습니다.

아세트산 CH₃COOHCH₃COOH ⇌ H⁺ + CH₃COO⁻약산 / 일부만 이온화

중화 반응의 핵심

H⁺ + OH⁻ → H₂O
수소 이온과 수산화 이온이 1 : 1로 반응하여 물을 만듭니다. 반응 후 용액의 액성은 어느 이온이 남는지로 판단합니다.

염산과 수산화 나트륨의 반응

HCl → H⁺ + Cl⁻→NaOH → Na⁺ + OH⁻→H₂O + Na⁺ + Cl⁻

전체 반응식: HCl + NaOH → NaCl + H₂O. Na⁺와 Cl⁻는 이 중화 반응에 직접 참여하지 않고 수용액에 남는 구경꾼 이온입니다.

반응 전 H⁺와 OH⁻반응 후 남는 주요 이온혼합 용액
H⁺ > OH⁻H⁺가 남음산성
H⁺ = OH⁻중화에 직접 참여한 두 이온이 모두 소모됨염산·NaOH 모형에서는 중성
H⁺ < OH⁻OH⁻가 남음염기성
같은 부피를 섞었다고 항상 중성이 되는 것은 아닙니다. 농도와 H⁺·OH⁻의 개수 비를 확인해야 합니다. 이 페이지의 액성 모형은 완전히 이온화된 강산·강염기를 가정합니다.

중화열과 온도 변화

중화 반응에서 열이 발생합니다. 이때 발생하는 열을 중화열이라고 합니다. 같은 반응 조건에서는 생성된 물의 양이 많을수록 방출되는 열도 커집니다.

원본 실험은 염산과 NaOH 수용액의 농도·초기 온도가 같고 전체 부피가 12 mL인 조건입니다. 온도가 가장 높은 조합은 6 mL + 6 mL이며, 두 반응 이온이 가장 많이 반응합니다.

“최고 온도 = 중화점”은 이 실험의 통제 조건에서 해석하세요. 전체 질량·초기 온도·열 손실 조건이 달라지면 단순한 온도 비교만으로 생성 물의 양을 판단할 수 없습니다.

중화점반응에 쓸 H⁺가 소모됨반응에 쓸 OH⁻가 소모됨존재존재

위 표는 일정량의 염산에 NaOH 용액을 더하는 모형입니다. 이온 수와 이온 농도를 혼동하지 마세요. Cl⁻의 수는 일정해도 전체 부피가 커지면 농도는 감소합니다.

이산화 탄소의 고체화

CO₂를 포집해 수산화 칼슘 수용액과 반응시키면 탄산 칼슘 고체로 저장할 수 있습니다.

CO₂를 탄산 칼슘으로 저장

CO₂ 포집→Ca(OH)₂ 수용액과 반응→CaCO₃ 고체 생성·저장

CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O
물을 거쳐 탄산으로 표현하면 H₂CO₃ + Ca(OH)₂ → CaCO₃↓ + 2H₂O입니다. 아래 화살표는 침전 생성을 뜻합니다.

에너지를 방출하거나 흡수하는 변화

에너지 방출

계에서 주위로 에너지가 이동합니다. 열을 방출하면 주위 온도가 올라갑니다. 예: 연료의 연소, 산화 칼슘과 물의 반응, 철의 산화가 일어나는 손난로, 중화 반응.

에너지 흡수

주위에서 계로 에너지가 이동합니다. 열을 흡수하면 주위 온도가 내려갑니다. 예: 냉각 팩의 반응, 드라이아이스의 승화, 냉매의 기화.

상태 변화와 에너지 방향

에너지 흡수에너지 방출방향을 읽는 예
융해: 고체 → 액체응고: 액체 → 고체얼음을 녹이려면 열을 공급
기화: 액체 → 기체액화: 기체 → 액체땀 증발은 주변의 열을 흡수
승화: 고체 → 기체승화: 기체 → 고체드라이아이스가 기체로 변할 때 흡열

냉장고의 냉매

내부에서 기화 · 열 흡수→압축·이동→외부에서 액화 · 열 방출

냉장고 안의 열이 바깥으로 이동합니다. 냉장고는 전기 에너지를 사용하며, 뒤쪽 방열판에서는 냉매가 액화하는 과정에서 열이 나옵니다.

에너지의 “출입”은 계와 주위 사이의 이동입니다. 에너지가 새로 생기거나 사라진다는 뜻이 아닙니다. 계가 열을 흡수하면 주위는 열을 잃습니다.
