✏️ 화학 반응식의 문법

6CO2 + 6H2O ⟶ C6H12O6 + 6O2
요소표기뜻
반응물 → 생성물화살표 왼쪽 / 오른쪽반응 전 물질 / 반응 후 새로 생긴 물질
계수화학식 앞의 큰 숫자 6CO2그 물질의 개수(입자 수의 비). 1은 생략한다.
아래 첨자원소 기호 오른쪽 아래 작은 숫자 CO2한 물질 속 그 원자의 개수. 바꾸면 다른 물질이 된다.
기체 발생↑생성된 기체가 빠져나감 예) CO2↑, H2↑
이온의 전하오른쪽 위 첨자 Cu2+ O2−숫자 먼저, 부호 나중(2+, 2−). 1은 생략(Ag+, Cl−)
⚠️ 계수 vs 아래 첨자: 2H2O는 '물 분자 2개'(H 4개, O 2개)이다. 원자 수를 맞추려고 아래 첨자를 바꾸면 전혀 다른 물질이 되므로, 원자 수는 반드시 계수로만 맞춘다.

⚖️ 질량 보존 법칙

질량 보존 법칙
화학 반응이 일어날 때 반응 전 물질의 총질량 = 반응 후 물질의 총질량
원자는 새로 생기거나 사라지지 않고→ 결합만 바뀌어 재배열된다→ 원자의 종류와 개수가 반응 전후 같다→ 질량 보존
✅ 그래서 화학 반응식은 화살표 양쪽의 원자 개수가 같도록 계수를 맞춰야 완성된다.

⚡ 이온과 이온 화합물 읽기

양이온

전자를 잃어 (+) 전하를 띠는 입자

예) H+, Na+, K+, Ag+, Mg2+, Ca2+, Cu2+, Fe3+

음이온

전자를 얻어 (−) 전하를 띠는 입자

예) Cl−, OH−, NO3−, CH3COO−, O2−, SO42−, CO32−

💡 NO3−, SO42−, CO32−, OH−, CH3COO−처럼 여러 원자가 한 덩어리로 움직이는 이온은 통째로 기억한다.

이온 화합물 판단법 — 양이온 + 음이온으로 쪼개기

3단계

1
앞쪽 = 양이온(금속), 뒤쪽 = 음이온(덩어리 이온 포함)으로 나눈다.

3
이온 화합물은 전하의 총합 = 0이다. 모르는 양이온의 전하는 이것으로 구한다.

📌 01. 산화·환원 반응의 규칙성
🧭 흐름 — 역사 속 화학 반응의 공통점(산소) → 산화·환원의 정의(산소 기준) → 실험으로 확인 → 동시성

🌍 자연과 인류의 역사를 바꾼 화학 반응

①광합성 생물의 등장 — 바다에 광합성을 하는 남세균이 생겨나면서 지구 대기에 산소가 쌓이기 시작했다.
6CO2 + 6H2O ⟶ C6H12O6 + 6O2
②산소 호흡을 하는 생물의 등장 — 산소를 이용해 영양소를 분해하고 에너지를 얻는 생물이 등장했다.
C6H12O6 + 6O2 ⟶ 6CO2 + 6H2O
③오존층 형성 — 대기 중 산소로부터 오존층이 형성되어 자외선을 흡수 → 생물이 바다에서 육지로 올라옴
④철의 제련 — 철광석(산소와 결합된 산화 철)에서 산소를 떼어 내는 기술 → 철기 문명
⑤화석 연료의 사용 — 석탄, 석유, 천연가스를 산소와 반응시켜(연소) 얻은 열에너지로 산업 발전
공통점
광합성, 철의 제련, 화석 연료의 사용에 공통으로 관여한 원소는 산소이다. 이처럼 산소의 이동에 의한 반응을 산화·환원 반응이라고 한다.

📐 산화와 환원 — 산소 기준

산화

물질이 산소를 얻는 반응

환원

물질이 산소를 잃는 반응

🧪 해 보기: 산화 구리(Ⅱ)와 숯가루의 반응

시험관에 산화 구리(Ⅱ) + 숯가루→ 가열→ 검은색 가루 → 붉은색 구리 석회수가 뿌옇게 흐려짐 → CO2 발생
2CuO + C ⟶ 2Cu + CO2
반응물생성물
환원CuO → Cu : 산소를 잃음
산화C → CO2 : 산소를 얻음

산화 구리(Ⅱ)에서 산소가 분리되어 구리가 생성되고(환원), 이와 동시에 분리된 산소가 숯가루의 탄소와 결합하여 이산화 탄소가 생성된다(산화).

✅ 산화와 환원은 항상 동시에 일어난다 — 한 물질이 잃은 산소를 다른 물질이 얻기 때문이다.

🔩 철이 녹스는 반응

4Fe + 3O2 ⟶ 2Fe2O3

철(Fe)이 공기 중에 오래 노출되면 산소와 만나 서서히 산화되어 붉은색의 산화 철(Ⅲ)이 된다. 은회색 철과 성질이 달라 붉은색을 띠고 광택이 없다.

💡 페루의 무지개 산 일부가 붉게 보이는 까닭도 흙에 산화 철(Ⅲ)이 많기 때문이다.
📌 01. 산화·환원 반응의 규칙성
🧭 흐름 — 산소 기준의 한계 → 전자 기준 정의 → 철·구리·마그네슘에 적용 → 양이온 관점에서 꼭 알아 둘 것(전하량 불변) → 참고: 금속의 반응성·산화수

❓ 왜 전자로 설명할까?

산소가 관여하지 않는 산화·환원 반응도 있고, 산소가 관여해도 산소의 이동만으로는 설명하기 어려운 경우가 있다.

철이 녹스는 반응을 전자로 보면

4Fe + 3O2 ⟶ 2Fe2O3

생성물 산화 철(Ⅲ)을 구성하는 이온은 Fe3+과 O2−이다.

철: 산화

전자를 잃어 Fe3+이 된다.

산소: 환원

전자를 얻어 O2−이 된다.

📐 산화와 환원 — 전자 기준

구분산소 기준전자 기준양이온 관점에서 보면
산화산소를 얻음전자를 잃음금속 원자 → 양이온 (예: Cu → Cu2+)
환원산소를 잃음전자를 얻음양이온 → 금속 원자 (예: Ag+ → Ag)
✅ 한 물질이 잃은 전자를 다른 물질이 얻으므로 산화와 환원은 동시에 일어난다.

🧪 탐구: 구리와 질산 은 수용액의 반응

구리줄 표면을 사포로 문지름→ 원하는 모양으로 만들어 페트리 접시에→ 질산 은 수용액에 잠기도록 넣음→ 수용액 색과 구리줄 표면 관찰

수용액

무색 → 점점 푸른색 (구리 이온 Cu2+ 생성)

구리줄 표면

은(Ag)이 석출되어 달라붙음
Cu + 2AgNO3 ⟶ Cu2+ + 2Ag + 2NO3−

↓ 반응에 참여하지 않는 NO3−을 빼고 이온만 쓰면

Cu + 2Ag+ ⟶ Cu2+ + 2Ag
산화Cu ⟶ Cu2+ + 2e− : 구리가 전자 2개를 잃음
환원2Ag+ + 2e− ⟶ 2Ag : 은 이온 2개가 전자를 1개씩 얻음

🔒 양이온 관점에서 꼭 알아 둘 것 — 전하량 불변

규칙 ① 잃은 전자 수 = 얻은 전자 수

구리 1개가 잃은 전자 2개를 은 이온 2개가 1개씩 나누어 얻는다. 그래서 반응식에서 Ag+의 계수가 2이다.

규칙 ② 반응 전후 전하의 총량은 변하지 않는다

반응 전반응 후변화
수용액 속 양이온2Ag+Cu2+개수 2 → 1 (감소)
양이온의 전하 총량(+1) × 2 = +2(+2) × 1 = +2불변
NO3− (음이온)2개2개변화 없음 (반응에 참여 X)
✅ 핵심: 양이온의 '개수'는 변할 수 있지만 전하의 '총량'은 변하지 않는다. 음이온(NO3−)이 그대로이므로 양이온의 전하 총량도 그대로여야 한다.
이온 반응식도 화살표 양쪽의 원자 수와 전하 합이 모두 같아야 한다. (Cu + 2Ag+ ⟶ Cu2+ + 2Ag : 왼쪽 +2 = 오른쪽 +2)

🔥 마그네슘의 산화·환원

마그네슘 리본을 공기 중에서 가열하면 마그네슘이 산소와 반응하여 산화 마그네슘이 된다.

2Mg + O2 ⟶ 2MgO ( 2MgO = 2Mg2+ + 2O2− )
산화Mg → Mg2+ : 전자를 잃음
환원O2 → O2− : 전자를 얻음
💡 산소 기준으로 보아도 마그네슘은 산소를 얻었으므로 산화이다. 두 기준은 서로 모순되지 않는다.

🔢 산화수 눌러서 펼치기

산화수 규칙

  1. 홑원소 물질의 산화수는 0이다.
  2. 단원자 이온의 산화수는 이온의 전하와 같다. 예) Ag+ → +1
  3. 다원자 이온은 각 원자 산화수의 합 = 이온의 전하 예) NO3− → 합 −1
  4. 화합물은 산화수의 총합이 0이다.

산화수 우선 규칙 (위에 있을수록 먼저 적용)

  1. 1족, 2족, 3족 금속: +1, +2, +3
  2. F: −1
  3. H: +1
  4. O: −2
  5. C > N > S
  6. Cl > Br > I
물질산화수설명
H2O2H +1, O −1H(+1)가 O(−2)보다 우선
OF2O +2, F −1F(−1)가 O(−2)보다 우선
KO2K +1, O −½1족 K(+1)가 O(−2)보다 우선
NaHNa +1, H −11족 Na(+1)가 H(+1)보다 우선
💡 산화수가 증가하면 산화, 감소하면 환원이다. 예) 산화 구리(Ⅱ) CuO에서 구리의 산화수는 +2, 산화 철(Ⅲ) Fe2O3에서 철의 산화수는 +3이다.

환원Fe2O3 → Fe (산소를 잃음)
산화CO → CO2

용광로에 철광석, 코크스(C), 석회석을 넣는다. 코크스가 산소와 결합하여 일산화 탄소가 된 후 산화 철(Ⅲ)을 환원시킨다.

✅ 판단 요령: 반응물에서 생성물로 갈 때 산소가 붙으면 산화, 산소가 떨어지면 환원. 메테인 연소에서 산화되는 물질은 CH4, 철의 제련에서 환원되는 물질은 Fe2O3이다.

철의 제련에서 석회석의 역할 — 불순물 제거

1CaCO3 ⟶ CaO + CO2 석회석이 열분해된다.
2CaO + SiO2 ⟶ CaSiO3 불순물과 결합해 슬래그가 된다.
슬래그 (CaSiO3) — 가벼워서 위에 뜸
철 (Fe)

🏠 생활 속 산화·환원

장소사례일어나는 일
집섬유 표백누렇게 변한 옷에 표백제를 넣으면 산화·환원 반응이 일어나 옷이 하얗게 된다.
집양초주성분인 파라핀이 연소되어 이산화 탄소와 수증기로 변한다.
길손난로철이 산소와 반응하여 산화 철(Ⅲ)로 산화될 때 열이 발생한다.
길자동차 배기관 촉매 장치산화 질소가 환원되어 배기가스가 정화된다.
학교리튬 배터리리튬이 전자를 잃고 산화된 뒤 양극에서 음극으로 이동하며 충전된다.
학교과일의 갈변사과, 배, 바나나, 복숭아의 폴리페놀 성분이 산화되어 갈변한다.
자연반딧불이광세포에서 루시페린이 산화되면서 빛에너지를 방출한다.
💡 철은 자연에서 산화 철의 형태로 존재하므로 그대로 쓰기 어렵다 → 산화·환원 반응을 이용한 제련으로 순수한 철을 얻어 문명을 발전시켰다. 또 화석 연료를 연소시켜(산화) 많은 에너지를 얻는다.

🏠 우리 주변의 산과 염기

산

  • 식초: 아세트산
  • 과일: 비타민 C 등의 산
  • 해열제·진통제: 살리실산, 아세틸 살리실산
  • 산성비: 화석 연료 연소 시 배출된 황산화물, 질소 산화물로부터 생성된 황산, 질산
  • 해양 산성화: 대기 중 CO2가 바다에 더 많이 녹아 해수 표면의 H+ 농도가 높아짐

염기

  • 유리 세정제: 기름 성분 제거를 위한 염기 성분
  • 비누: 수산화 나트륨으로 세탁 비누를 만듦
  • 세제: 빨래의 찌든 때 세탁
  • 혈액: 약한 염기성
  • 염기성 호수: 탄자니아의 나트론 호수
💡 수국의 꽃잎은 산성 토양에서는 푸른색, 염기성 토양에서는 붉은색으로 피어난다. 소화 효소 중에도 산성이나 염기성을 띠는 것이 있다.

염화 수소(HCl)는 물에 녹아 묽은 염산이 될 때 수소 이온(H+)과 염화 이온(Cl−)으로 이온화된다. 여기에 전극을 넣고 전원 장치를 연결하면 이온들이 전극으로 움직이며 전류가 흐른다. 수산화 나트륨 수용액도 Na+과 OH−으로 이온화되어 같은 까닭으로 전류가 흐른다.

🪞 산과 염기 — 거울처럼 비교

산

  1. 수용액에서 H+을 내놓는다.
  2. 양이온이 같고(H+), 음이온은 산의 종류에 따라 다르다.
  3. 공통 성질의 원인: H+

염기

  1. 수용액에서 OH−을 내놓는다.
  2. 음이온이 같고(OH−), 양이온은 염기의 종류에 따라 다르다.
  3. 공통 성질의 원인: OH−
💡 이온화식도 반응식이므로 화살표 양쪽의 원자 수와 전하 합이 같다. 예) H2SO4 ⟶ 2H+ + SO42− : 왼쪽 0 = 오른쪽 (+2) + (−2)
