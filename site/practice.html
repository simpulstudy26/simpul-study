필요조건과 충분조건 서술형 연습

두 조건 p, q의 관계를 판단하고 근거를 쓰는 연습이에요. 문제는 누를 때마다 새로 만들어져요.

p ⇒ q가 참이면 p는 q의 충분조건, q는 p의 필요조건

성립하지 않는 방향은 반례 하나로 보여 주면 돼요. 두 방향이 모두 참이면 필요충분조건이에요.

역함수 개념과 기본 문제

역함수를 구하는 순서를 확인하고 기본 문제 3개를 풀어 보세요.

함수 f가 x를 y로 보내면, 역함수 f⁻¹는 y를 다시 x로 돌려보내요. 일대일대응인 함수만 역함수를 가져요.

y = f(x)에서 x와 y를 바꾼 뒤 y에 대해 정리하면 y = f⁻¹(x)

원래 함수의 정의역과 치역은 역함수에서 서로 바뀌어요. f⁻¹(x)는 1/f(x)와 달라요.

문항 1

실수 전체에서 정의된 함수 f(x) = 2x + 3의 역함수 f⁻¹(x)를 구하시오.

정답 보기

정답: f⁻¹(x) = (x − 3)/2

해설: y = 2x + 3에서 x와 y를 바꾸면 x = 2y + 3이다. y에 대해 정리하면 y = (x − 3)/2이다.

문항 2

실수 전체에서 정의된 함수 f(x) = 3x − 2에 대해 f⁻¹(7)의 값을 구하시오.

정답 보기

정답: 3

해설: f(a) = 7이면 3a − 2 = 7이므로 a = 3이다. 따라서 f⁻¹(7) = 3이다.

문항 3

함수 f: [0, ∞) → [0, ∞), f(x) = x²의 역함수와 그 정의역을 구하시오.

정답 보기

정답: f⁻¹(x) = √x, 정의역은 [0, ∞)

해설: x와 y를 바꾸면 x = y²이다. 원래 함수의 정의역에 따라 y ≥ 0이므로 y = √x이다. 역함수의 정의역은 원래 함수의 치역인 [0, ∞)이다.
